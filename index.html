Selected work

  • Language to robot navigation

    MSc dissertation, Middlesex University, 2026

    An LLM planner that turns typed commands into schema-checked Nav2 plans over a semantic map of a simulated warehouse, then executes them on a ROS 2 robot in Gazebo. I built a 100-command benchmark across five levels of difficulty. Direct and multi-step commands land at 95–97%; conditionals at 55%, a gap I traced to the plan format rather than the model.

    Code and results Research blog

  • IntelliChat

    Enhance Intelligence & Technologies, Dubai, 2026

    A multi-tenant assistant that answers business questions by writing SQL against live Oracle ERP data, across nine business domains. Around 80% of real queries succeed end to end. I built the two-layer semantic cache (Redis over Oracle 23ai vector search), embedding-based domain routing that cut prompt size by 50–60%, and row-level tenant isolation.

    Client product, code is private

  • Sandsifter

    Beach-cleaning robot, MSc project

    A ROS 2 Humble and Gazebo simulation of an autonomous beach cleaner, with a ros2_control arm and my own boustrophedon coverage planner that sweeps the whole area while avoiding obstacles.

    Code

  • Visual quality inspection

    MSc project

    A MobileNetV2 transfer-learning classifier for pass/fail packaging inspection. I collected and augmented the data, then trained and evaluated the model, reaching about 95% validation accuracy.

    Code

  • Multi-agent operations assistant

    Independent build, 2026

    LangGraph routing across sales, finance, distribution and service agents over a 20-table ERP dataset, with RAG product search and n8n automations that send real emails. I demonstrated it live to a distributor's department heads.
